# HailoRT Python wheel

This directory contains the HailoRT Python wheel used by the Docker build. It
matches all of the following:

- HailoRT major/minor version used by the host driver and firmware (4.23.x)
- Python 3.11 (`cp311`)
- Linux aarch64

Included filename:

```text
hailort-4.23.0-cp311-cp311-linux_aarch64.whl
```

The Raspberry Pi host driver, firmware, shared library, and this wheel must use
compatible HailoRT versions.
